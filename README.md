# Numerical Methods for Partial Differential Equations

Python implementations of numerical methods studied in the *PDEs and Numerical Methods* course of the Master's programme in Applied Mathematics at Université Grenoble Alpes / Grenoble INP.

## Overview

This repository contains practical assignments exploring numerical approximation, finite difference schemes and the numerical solution of partial differential equations (PDEs).

The main focus is on implementing numerical methods, evaluating their accuracy and studying their convergence properties.

## Topics

### 1. Numerical Approximation and Visualization

- Visualization of the Mandelbrot set
- Least-squares approximation and linear fitting
- Computation of L1, L2 and L∞ errors

### 2. Finite Difference Methods

- Numerical approximation of first and second derivatives
- Finite difference stencils
- Second- and fourth-order accurate schemes
- Periodic boundary conditions
- Error estimation and convergence analysis

### 3. Transfer Function Analysis

- Transfer functions of finite difference operators
- Forward, backward and centered difference schemes
- Amplitude amplification factors
- Phase errors and their dependence on spatial discretization

### 4. Numerical Solution of a 1D Diffusion Equation

- Steady-state diffusion equation with spatially varying coefficients
- Dirichlet and mixed boundary conditions
- Finite difference discretization
- Construction and solution of linear systems
- Comparison with analytical solutions
- Numerical error and convergence analysis

## Technologies

- Python
- NumPy
- SciPy
- Matplotlib
